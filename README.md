# Bizgroww — Digital Growth Agency Landing Page

A modern, high-converting landing page built for **Bizgroww**, a digital growth agency helping businesses scale through tailored strategy, design, and performance marketing.

## 🚀 Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
